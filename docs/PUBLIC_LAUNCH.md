# 面向中国学生的公开版：范围与开关

更新：2026-10-08。取消“接近 Turnitin”的目标；不增加查重、相似度数据库、Copyleaks 或学校检测规避承诺。

## 当前可公开范围

公开首页、帮助/使用/隐私说明，以及无需账号的浏览器本地写作体验。规则检查长句、重复段落、缺少来源提示；可审阅固定规则示例、接受/拒绝、撤销和导出 TXT。不会计算 AI 百分比、调用模型或上传正文。正文仅在页面内存中，关闭/崩溃可能丢失；离开前导出，浏览器关闭提示不是持久备份。资源加载及公开状态请求会产生普通托管网络元数据；没有添加分析追踪器。

云端保留所有者工作台，学生注册和公众真实 AI 默认关闭。本轮完成了云端账号与中文处理代码，**不代表已经开放公众云端服务**。运营主体与联系邮箱尚未确定，不生成虚假主体、备案号或联系方式。

## 配置职责（后端 Railway api Variables）

| 变量 | 默认 | 含义 |
|---|---|---|
| PUBLIC_REGISTRATION_ENABLED | 0 | 注册入口与后端创建账号开关 |
| PUBLIC_AI_ENABLED | 0 | 学生真实 Provider 调用开关，不影响所有者现有模式 |
| PUBLIC_LAUNCH_ACKNOWLEDGED | 0 | 运营者已完成下列上线检查的声明，不替代合规判断 |
| PAPERLIGHT_OPERATOR_NAME | 空 | 真实运营主体名，公开显示 |
| PAPERLIGHT_SUPPORT_EMAIL | 空 | 可联系的邮箱，公开显示，绝非密钥 |
| PUBLIC_MAX_ACCOUNTS | 200 | 首阶段账户容量，不是任意增长的注册池 |
| GLOBAL_PAID_HOURLY_LIMIT | 20 | 所有用户、Provider、阶段合计的调用预留硬上限 |
| GLOBAL_PAID_DAILY_LIMIT | 50 | 滚动24小时合计硬上限 |

Key 仍仅属于后端变量；不可复制到 NEXT_PUBLIC、GitHub Pages、文档、错误或聊天。前三项保持0即可发布本地体验，无需新凭据。不要为本轮发布更改 Pangram/DeepSeek Key、费用授权或 TOTP。

开启任何公众云端开关时，配置验证要求主体、有效联系邮箱与上线确认；生产还要求 PostgreSQL 与 Redis。身份注册限流使用 Redis 原子计数，Redis 故障会失败关闭；恢复码接口也应在开放云端后使用分布式限制。上线声明是技术门槛，不是法律许可。

## 中文文稿与修改

- 云端中文500–12,000字/词，英文500–5,000词；总字符100,000，最大400段，每段最多40,000字符。CJK统一字符加ASCII词计数，前后端一致；中英混合依字符占比启发式显示单位，不是分词学术标准。长论文由作者分章提交，不会自动裁掉超长正文。
- DOCX 转为纯文本；公式、脚注、绘图、修订和复杂表格继续拒绝，以免默默丢失学术结构。请保留 Word 原稿。这一限制不因中文支持而消失。
- DeepSeek 提示要求保持原文语言，仍先建议、校验、用户接受再创建版本；数字、URL、引用、引文、缩写和书名受保护。中文专业名词不能仅靠正则全面识别，模型校验也不能代替作者核验。
- 接受过真实 AI 建议的文稿导出 DOCX 时，在页脚和core properties comments添加来源说明，不改正文。Mock规则示例不被伪称模型生成；未接受的真实建议不标记。该说明记录“写作过程中使用过”，不判断当前每句来源，也不宣称已满足完整国家文件标识标准。
- Pangram官方模型卡包含中文支持，但这不等于已独立验证中国学生课程论文误报率：[Pangram 4 model card](https://www.pangram.com/research/model-card/pangram-4)。开公众检测前需要授权中文样本的分组评测；不得把供应商性能宣传变为 Paperlight 自有成绩。

## 学生账号与数据隔离

首阶段仅18岁以上；用户名3–32位ASCII、密码至少12字符、Argon2id哈希。无需姓名、学号、学校、邮件。恢复码随机生成、仅存哈希、创建/恢复时一次展示；恢复后旧码失效并撤销旧会话。丢失密码和恢复码时无法自动恢复，运营流程不得随意替换账号密码。恢复码放密码管理器，不发送客服或截图。

客户端不能指定角色、principal或所有者。Session绑定账号及密码版本；文稿、补丁、检测、版本、任务和导出都先校验账号归属。学生不会因为BILLING_MODE=disabled获得所有者Pro权限；默认Free容量和操作额度仍有效。真实AI默认被后端拒绝，注册时不捆绑供应商处理授权；未来单独授权后可撤回。说明版本更新后旧授权失效。

注销要求当前密码；有活跃/欠费订阅时先解决订阅。删除正文、版本、检测、建议、任务、对象及会话；无客户支付/结算关联的免费套餐记录也删除。Provider调用风控账本默认30天。有关真实客户支付/结算的无正文记录不由通用注销接口删除，具体财务保存期限须在收费开放前确定并告知；当前公众收费仍关闭。文稿保留7天并自动清理，不向用户承诺供应商副本或已下载文件被本地删除。删除任务关联数据不等于能撤销已提交给外部供应商的工作。

## 费用保护边界

浏览器体验零Provider调用；基础托管仍可能有现有套餐用量费用，不等于整体运营零成本。云端不会编辑/保存时自动复检。真实调用受单人额度、全站额度、内容哈希、并发/事务锁、失败熔断、有限轮询和一次性领取限制。全站预留锁依赖PostgreSQL；SQLite本地测试不能证明跨进程数据库锁的生产并发性能。

一次DeepSeek改写包含Pro生成和Flash校验两个计量阶段；按阶段预留，不是把两个阶段视为一次免费任务。额度是调用次数，不是人民币硬上限，供应商账单仍是费用来源。未授权新付费验收、本轮不调用真实Provider，不充值、不购买、不改变客户付费模式。

## 公众云端上线顺序（尚未完成）

1. 确定真实运营主体与可联系邮箱，并由运营者确认面向中国用户的服务性质、登记/备案、未成年人及生成内容标识要求。
2. 逐项确认实际云服务区域、Pangram/DeepSeek处理范围、保存/训练/删除条款，完善个人信息告知和适用跨境处理安排，不能只写“境外”后就开放。
3. 轮换历史上曾暴露的所有者密码、验证旧会话失效，妥善保存凭据与恢复资料；本轮不恢复TOTP，保持用户当前选择。
4. 评估国内网络可达性；GitHub Pages/Railway大陆学校网络可达性尚未验收，按需求选国内托管/域名后再考虑备案，不自动采购。
5. 完成授权中文基准、PostgreSQL多用户并发、Redis断连、七天删除、备份恢复、供应商失败和费用上限的云端验收。
6. 首先开小规模邀请试用，确认支持/删除/投诉响应、容量和成本，再决定开放注册；当前自助注册代码无验证码或邀请机制，大规模开放前需防滥用补强。
7. 真实AI需另行明确少量付费授权和处理说明后开放；收费、定价、退款和支付方式另行批准，不能从已有Stripe适配推断公众收费就绪。

## 发布与回退

升级自动执行Alembic，新增user_accounts表，重复升级安全，不清空旧文稿。公众开关缺省关闭；核验 `/api/v1/public/config` 的 registrationEnabled/publicAiEnabled 均false。生产密码/TOTP/Key不需读取，公开状态查询只输出安全标识。

代码回退可部署上一提交，继续保持开关0，不自动降级数据库；新表对旧代码可保留。若真需要降级该迁移，应先暂停云端注册、备份并确认不丢学生账号，再按指定前一revision操作。禁止直接downgrade base或清空数据库。

验证命令：Python pytest tests、pnpm test/typecheck/build/check:secrets、pnpm audit --prod、pip-audit、隔离staging build/smoke及桌面/手机渲染。生产Smoke只证明匿名发布布线，不能替代登录/付费/公众合规验收。
